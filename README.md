# Odin Recipes Project

This project is a simple recipe website created as part of The Odin Project Foundations course. It consists of an index page that links to individual recipe pages for Masala Paneer, Egg Curry, and Gajar Ka Halwa.

## Project Overview
The main goal of this project was to practice building basic HTML pages, linking between pages, and structuring content in a clear and organized way. Each recipe page contains a description, a list of ingredients, and step-by-step instructions.

## Skills Demonstrated
By completing this project, I have practiced and demonstrated the following skills:
- Creating and structuring HTML pages
- Linking multiple pages together using anchor tags
- Organizing content with headings, paragraphs, lists, and images
- Writing clear and readable code

## Reflection
Working on this project helped me solidify my understanding of HTML basics and how to create a small, navigable website. It also gave me a sense of how to structure content so that it is user-friendly and visually clear.
